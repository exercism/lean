# Design

## Goal

The goal of this exercise is to teach the basics of defining values and functions in Lean.

## Learning objectives

- Know how to define a named constant with `def`.
- Know how to define a function with one or more parameters, using `def`.
- Know that a top-level `def` needs an explicit type for every parameter and for its return value.
- Know how to call a function, including from inside another function.
- Know how to use `#eval` to try out an expression.
- Know how to write line and block comments.

## Out of scope

- Everything about `Nat` and `Int` beyond simple literals and `+ - *` (see the `numbers` concept).
- Other types and expressions.

## Concepts

`basics`:

- defining values and functions with `def`
- explicit parameter and return types
- calling a function
- `#eval`
- comments

There are no prerequisites for this exercise.
