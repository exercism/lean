# Design

## Goal

The goal of this exercise is to teach `Nat` and `Int` arithmetic in Lean.

## Learning objectives

- Know that `Nat` is for non-negative whole numbers, and has no fixed upper limit.
- Know that `Int` is for whole numbers that can be negative.
- Know how to use `+ - * / %` on `Nat` and `Int`.
- Know that `Nat` subtraction is truncated at `0`.
- Know that a negative literal needs parentheses as a function argument.

## Out of scope

- Comparison operators (`< <= > >= == !=`) are mentioned in the concept text but not tested here.
- `Float` and other numeric types.
- Overflow behavior of fixed-width integer types (`Nat`/`Int` are unbounded).

## Concepts

`numbers`:

- `Nat` and `Int` literals
- arithmetic operators `+ - * / %`
- `Nat` truncated subtraction
- negative `Int` literals and the parentheses they need as arguments

## Prerequisites

- `basics`
